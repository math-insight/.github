# Współtworzenie projektów Insight

Przed zmianami przeczytaj README i instrukcje danego repozytorium.

- Błędy i propozycje zgłaszaj w Issues właściwego repozytorium. Sprawdź wcześniej, czy podobne zgłoszenie już istnieje.
- Przy większych zmianach najpierw opisz propozycję w Issue.
- Przygotuj zmiany na osobnej gałęzi i otwórz pull request z opisem celu oraz sposobu sprawdzenia.
- Zachowuj istniejące konwencje projektu. Aktualizuj dokumentację, jeśli zmieniasz sposób uruchomienia lub użycia.
- Nie publikuj haseł, tokenów, danych osobowych ani danych, do których udostępnienia nie masz uprawnień.

Szczegółowe instrukcje w poszczególnych repozytoriach mają pierwszeństwo przed tymi wskazówkami.
